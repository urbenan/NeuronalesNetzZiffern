# Neuronales Netz erkennt Ziffern

Ein kleines neuronales Netz (10×10 Pixel) erkennt handgeschriebene Ziffern – direkt im Browser, ohne Server.

## Seiten

- **[Ziffern erkennen](https://urbenan.github.io/NeuronalesNetzZiffern/web/)** – Ziffer zeichnen, das Netz rät
- **[Netz beim Lernen](https://urbenan.github.io/NeuronalesNetzZiffern/web_lernen/)** – Training im Browser beobachten

## Offline auf dem iPhone

1. Link oben in **Safari** öffnen (einmal mit Internet)
2. Teilen-Symbol → **Zum Home-Bildschirm**
3. Danach startet die App vom Home-Bildschirm auch ohne Internet
